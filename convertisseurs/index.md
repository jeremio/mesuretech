# Convertisseurs

Choisissez une grandeur. La conversion se fait pendant la saisie. Le bouton ⇄ inverse les unités, et le lien de la page conserve la valeur et les unités choisies, pour le partager.

<CategoryGrid />

Les facteurs de conversion proviennent des définitions officielles (par exemple, 1 pouce = 0,0254 m exactement). Le détail de chaque unité est dans le [guide des unités](/guide/unites-de-mesure).
